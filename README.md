# Solar Company – Basic Landing Web Page

## 📄 Project Overview

This is a basic landing Web page designed for a fictional Solar Company. It aims to showcase the company's value proposition, services, and branding through a clean and minimal web interface. The project is implemented using **semantic HTML5** and styled using **pure CSS** without any frontend frameworks or libraries.

---

## 🚀 Features

- Responsive layout with semantic HTML structure.
- Clean, accessible, and maintainable CSS styling.
- Mobile-first design for better cross-device compatibility.
- Optimized for readability and usability.

---

## 🧱 Built With

- **HTML5** – Structure and layout.
- **CSS3** – Styling and responsiveness using media queries.
- No external libraries or frameworks used (e.g., Bootstrap, Tailwind, etc.).
